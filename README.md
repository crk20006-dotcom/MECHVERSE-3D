# MECHVERSE AI — flat deployment edition
Upload app.py and requirements.txt directly to the root of your GitHub repository. No modules folder is needed. Streamlit main file path: app.py. Python 3.11 recommended.

Streamlit Secrets:
```toml
NVIDIA_API_KEY = "YOUR_KEY"
NVIDIA_MODEL = "meta/llama-3.3-70b-instruct"
```
Never commit your key. Simulations work without it. Educational models, not certified engineering designs.
