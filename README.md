Upload all six files to the root of your GitHub repository. Deploy app.py on Streamlit Community Cloud. In Secrets set:

```toml
GROQ_API_KEY = "your-key"
GROQ_MODEL = "llama-3.3-70b-versatile"
```

Model availability depends on your account. Never commit keys. Simulations work without a key. The Groq tutor is a separate tab; paste readings manually. Models are educational Canvas projections, not WebGL solids or CFD/FEA. Graphs are fixed canvases. Reports download as HTML; use browser print for PDF.

Use the top navigation to open Tutorial Centre or AI Tutor — Chat. Switching sections may reset the simulation iframe. Default Groq model: openai/gpt-oss-120b.
